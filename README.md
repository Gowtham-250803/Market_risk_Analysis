# Market_risk_Analysis

## 🔍 Project Overview

AlphaPulse is a financial analytics dashboard designed to analyze portfolio risk, return behavior, and optimization strategies.
It helps investors understand asset relationships, predict future performance, and make informed investment decisions.

---

## 🎯 Objectives

* Analyze portfolio risk and return behavior
* Understand correlation between different asset classes
* Simulate future portfolio performance using Monte Carlo methods
* Identify optimal portfolios using Efficient Frontier

---

## 🛠️ Tools & Technologies

* Tableau (Data Visualization)
* CSV Dataset (Processed financial data)
* Financial Metrics:

  * Correlation
  * Rolling Volatility
  * Sharpe Ratio
  * Monte Carlo Simulation

---

## 📂 Dataset Description

The dataset includes:

* Crypto assets
* Energy sector stocks
* Healthcare stocks
* Technology stocks
* Historical returns and volatility data

---

## ⚙️ Project Workflow

1. Data Collection
2. Data Preprocessing
3. Risk & Statistical Analysis
4. Simulation & Modeling
5. Optimization
6. Data Visualization
7. Final Insights

---

## 📊 Dashboard Components

### 1. Correlation Matrix

Shows relationships between assets and helps identify diversification opportunities.

### 2. Monte Carlo Simulation

Simulates future portfolio performance under different scenarios (P25, P50, P75).

### 3. Rolling Volatility

Displays how portfolio risk changes over time.

### 4. Efficient Frontier

Illustrates the optimal risk-return tradeoff for portfolio selection.

---

## 💡 Key Insights

* Diversification reduces overall portfolio risk
* Higher risk portfolios tend to yield higher returns
* Market volatility significantly impacts investment outcomes
* Efficient frontier helps in selecting optimal portfolios

---

## 🚀 Conclusion

This project demonstrates how financial data can be transformed into actionable insights using visualization and statistical modeling techniques.
It is useful for investors, analysts, and financial decision-making.
